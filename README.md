# Моя Ферма - Сервис расчёта норм кормления

Кроссплатформенное веб-приложение (Flutter Web) для автоматизации расчётов кормления сельскохозяйственных животных. Сервис позволяет вести учёт поголовья, рассчитывать суточную и годовую потребность в кормах с учётом индивидуальных характеристик животного, а также вести общую статистику по хозяйству.

## 1. Анализ целевой аудитории и сценарии

**Целевая аудитория:** Владельцы личных подсобных хозяйств (ЛПХ) и небольших ферм в возрасте 25–55 лет. Это практичные люди, которые ведут учёт самостоятельно и ценят своё время. Они привыкли пользоваться смартфоном для бытовых задач, но не имеют доступа к дорогим ERP-системам для агробизнеса.

**Сценарии использования:**
1. **Планирование закупок на зиму:** Осенью фермеру нужно понять, сколько тонн сена и комбикорма потребуется для его поголовья, чтобы закупить всё по выгодной цене и не оставить скот голодным.
2. **Контроль продуктивности:** У коровы упал удой. Фермер открывает карточку животного, корректирует параметры продуктивности и видит, как изменилась её норма кормления.
3. **Быстрый доступ:** Выходя из дома в хлев, фермеру некогда вводить сложные пароли. Приложение использует PIN-код для мгновенного доступа к данным.

## 2. Концепции приложений

В ходе проектирования было разработано 3 концепции агро-приложений разной направленности. Для реализации выбрана **Концепция 1**, так как она решает самую острую боль фермера — сложность расчёта кормов.

### Концепция 1: «Моя Ферма» (Реализована)
**Направление:** Практический инструмент / Калькулятор.
**Суть:** Строгий рабочий сервис. Пользователь заносит карточки животных, а система автоматически считает нормы кормления.
**Ключевые функции:**
1. Авторизация и быстрый вход по PIN-коду.
2. Добавление карточек животных (КРС, МРС, свиньи, птица) с указанием веса, возраста и продуктивности.
3. Автоматический расчёт суточной и годовой потребности в кормах.
4. Формирование сводной таблицы расхода кормов по группам животных.
5. Личный кабинет с возможностью смены темы (светлая/тёмная).

### Концепция 2: «Агро-Академия» (Альтернатива)
**Направление:** Образовательное / Помощник для новичков.
**Суть:** Приложение не только считает корма, но и объясняет, как правильно кормить животных.
**Ключевые функции:**
1. База знаний по уходу и кормлению с/х животных.
2. Умный калькулятор кормов с пояснениями (почему норма именно такая).
3. Календарь сезонных работ и вакцинаций.
4. Дневник наблюдений за состоянием животных.

### Концепция 3: «Фермерский Двор» (Альтернатива)
**Направление:** Комьюнити / Маркетплейс.
**Суть:** Платформа для кооперации, обмена опытом и продажи излишков продукции.
**Ключевые функции:**
1. Калькулятор себестоимости продукции (расчёт кормов для бизнеса).
2. Доска объявлений для продажи излишков сена, молодняка или продукции.
3. Бартер (возможность обменять корма с другими фермерами).
4. Форум для обсуждения рационов и ухода за скотом.

## 4. Ключевые функции приложения (Концепция 1)

- **Безопасная авторизация:** Вход по логину и паролю, а также настройка быстрого входа по PIN-коду (с валидацией и ограничением попыток).
- **Дашборд:** Главный экран со сводной информацией о количестве животных и общей годовой потребности в кормах.
- **Управление животными (CRUD):**
    - Добавление, редактирование и удаление карточек животных.
    - Учёт веса, возраста, продуктивности (молочная/мясная/шерстяная) и условий содержания.
- **Умный расчёт кормов:**
    - Автоматический расчёт суточной и годовой нормы на основе биологических особенностей.
    - Формирование сводной таблицы расхода кормов по группам животных.
- **Адаптивный интерфейс:** Полная поддержка светлой и тёмной темы. Дизайн адаптирован под мобильные устройства (Safe Area) и десктоп.

## 5. Технологический стек и архитектура

- **Framework:** Flutter (Web / iOS / Android)
- **Язык:** Dart
- **Хранение данных:** shared_preferences (локальное сохранение без необходимости бэкенда)
- **Векторная графика:** flutter_svg

**Архитектура проекта (Clean Architecture):**
- `lib/models/` — Модели данных (User, Animal, FeedNorm).
- `lib/services/` — Бизнес-логика и работа с хранилищем (Singleton-сервисы).
- `lib/screens/` — Экраны приложения (Auth, Home, Farm, Profile).
- `lib/widgets/` — Переиспользуемые UI-компоненты.
- `lib/themes/` — Конфигурация светлой и тёмной тем.

## 6. Инструкция по локальному запуску

Для запуска проекта вам потребуется установленный Flutter SDK.

1. Клонируйте репозиторий:
   git clone https://github.com/vfnoshark/my_finances.git
   cd my_finances

2. Установите зависимости:
   flutter pub get

3. Запустите проект в режиме веб-сервера (рекомендуется для проверки):
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
   
   После запуска приложение будет доступно по адресу http://localhost:8080.

4. Для сборки релизной версии:
   flutter build web --release --base-href /my_finances/ --no-tree-shake-icons
